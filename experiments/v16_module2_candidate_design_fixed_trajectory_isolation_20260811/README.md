# v16 Module2 Candidate Design — Fixed-Trajectory Isolation

This directory freezes four Module2 design candidates before analysis, then evaluates their exact context membership and retrospective alignment against the existing v15 train trajectories and 247 C0-generated candidates.

It is not a v16 implementation and not an efficacy experiment. No method source, training run, API/model call, validation artifact, or test artifact was used. No image was generated.

Read `DESIGN_SPEC.md` and `design_variants.json` for the pre-analysis freeze, `DESIGN_REPORT.md` for the interpretation, and `design_recommendation.json` for the machine-readable decision. Derived evidence is in `tables/`.

The recommendation requires a future explicitly authorized Pilot. Historical C0 candidates cannot prove that a new context will generate better candidates.
