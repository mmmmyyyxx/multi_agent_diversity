preserving the released-code topology: static task definition, Planner steps,
Teacher/Critic/Student dialogue, Student revision, and full-dataset Target
evaluation/history/stopping. `Config.DATASET_PATH` is mapped to one frozen
Optimize-only universe; repository Validation50 and Test50 are inaccessible.

execution is authorized by this protocol commit.
