# Sequential Symmetry-Breaking Online Pilot — Native GEPA Feed

This future, separately authorized pilot replaces the earlier responsibility-
filtered local feed with `GEPA_NATIVE_FEED_V1`. Layer 2 selects the member and
responsibility overlay; GEPA owns its fixed Optimize-only train/Pareto split,
epoch-shuffled minibatches, parent selection, and Pareto tracking.

The unchanged prospective endpoints are:

- `T_commit`: first Common-Safe + Shadow-approved write-back;
- `T_pivotal`: first committed state with `sum(P_0..P_4) > 0`;
- `T_vote`: first committed state whose Optimize Vote exceeds baseline.

Every state persists sanitized categorical profiles, `P_0..P_4`, and state
hashes. Validation50 and Test50 are prohibited. This protocol is blocked on a
successful real-provider native-feed GEPA canary and has no API authorization.
