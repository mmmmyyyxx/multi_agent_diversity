# Native GEPA Feed V1

This opt-in branch compares Native GEPA with Native GEPA + Layer2. Both arms
use one frozen Optimize-only universe, the same deterministic 75/25 internal
train/Pareto split, official epoch-shuffled sampling, official parent/Pareto
selection, identical models, decision-procedure representation, and identical
native metric budget. The treatment adds only member allocation, the versioned
responsibility overlay, team evaluation, and safe write-back.

Repository Validation50 and Test50 are inaccessible during optimization.
No real-provider execution is authorized by this protocol commit.
