`MARS_SEARCH_CORE_WITH_LAYER2_EVIDENCE_V1`. The treatment replaces native
dataset selection with one immutable Layer-2 responsibility packet while
retaining Planner, Teacher, Critic, Student, prompt history and termination.

local-evaluation set and the evidence schedule before Layer 1 begins. Treatment
mode cannot read the global Optimize dataset or any unlisted example.
TeamMiniBatch, Full, Common-Safe, Shadow and write-back are unchanged.

revision and exact Target evaluation. It must record packet delivery, role-cycle
completion, zero global-dataset access and candidate return. Validation50 and
Test50 are inaccessible. This preparation authorizes no provider call.
