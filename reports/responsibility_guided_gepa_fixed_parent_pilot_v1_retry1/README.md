# Responsibility-Guided GEPA fixed-parent pilot v1

This is the zero-API preflight and freeze only. It defines six analytical, non-committing parent cases: coverage, margin-support, and direct-flip from each of Seeds76 and 77. No provider call, Test50 access, ExternalValidation optimization call, candidate generation, full evaluation, Shadow gate, or write-back occurred.

The eventual paired comparison is frozen as A0 current/full/current selector; A1 same current pool/progressive/current selector; B0 reflection/progressive/current selector; B1 same B pool/team-Pareto selector. A0/A1 and B0/B1 share their candidate pools respectively.

`PRE_API_FREEZE.json` is private execution evidence under `runs/`; this report contains only sanitized identifiers, hashes, and minibatch metadata. API execution requires a separate explicit authorization and must use COMMON_SOLVER_CONTRACT_V1.
