# RG-GEPA fixed-parent pilot ledger repair

The first authorized fixed-parent execution completed its analytical cells but
failed the strengthened accounting audit. Parent full-team Solver calls were
not persisted with stage attribution, so its partial ledger cannot support a
complete cost claim. The raw runtime evidence is preserved and is not used as
an audited scientific result.

The repaired executor now records every Solver invocation at invocation time,
requires an explicit `full_team` parent-stage record for each of six parents,
and records the twelve paired minibatch parent lookups per parent as explicit
cache reuses. The strict audit also validates token arithmetic and unique
provider-attempt identities.

This repair made no provider call, did not access validation or Test50, did not
modify historical evidence, and did not retry the pilot. A future retry must
use a fresh run root and a newly frozen pre-API registry.
