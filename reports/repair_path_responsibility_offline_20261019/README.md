# Repair-Path Responsibility 离线诊断

2026-10-19。结论：**数学定义成立，WHO/Pattern 排序差异明显，但现有候选证据不足以支持替换 V2.12。** 本次只新增独立诊断工具和证据；没有改变运行方法、Full/Shadow、停止规则或历史结果。真实 API、Validation/Test 原始数据读取均为 0；未提交、未推送。

## 范围与计算

输入为 [V2.7 Seed86 冻结实验](../../experiments/manifests/math_v27_seed86_precluster_continuation_v1.yaml) 已有 Optimize 轨迹，以 [当前 Count 规则](../../docs/design/COUNT_RESPONSIBILITY_V212.md) 为回顾性比较基线。历史源与当前方法不同，不能把本次重算称为 V2.12 的真实实验。

共有 50 次机会、6 个不同父团队、固定 150 道 Optimize 题，合计 900 个父状态—题目组合；逐机会重放是 7,500 个行事件。8,359 是重复机会下的成员错误事件数，并非独立题目数。读取 70 个历史导出候选的记录，31 个获得完整 Full，分属 23 次机会和 15 个父状态—目标成员组合。其余 39 个的完整收益未知。

Oracle 游戏把选中错误成员的票改为正确类，其他票固定；无效输出原来不投票，理想修复后成为有效正确票。使用冻结的等权等价类 plurality，最高票平局弃权。只读已冻结答案类和 Boolean 正确性，不重新解析答案或调用数学评分器。

精确计算 `v(S)`、`I_i=v({i})-v(∅)` 和标准 Shapley `φ_i`。`φ_i=I_i/m+Enabling_i`；Enabling 是“前面已完成其他理想修复后成为关键一步”的结构贡献，不等于实际编辑实现了长期因果收益。最多 32 个虚拟投票，采用有理数计算。

WHO 比较均保留历史失败次数折扣 `Σ责任/(1+failure_count)`、历史候选成员集合和正分并列规则。历史失败次数也是旧算法产生的条件，不反事实更新。Pattern 固定**原实际目标成员**的已生成 partition，只重算每个唯一 support 的责任之和；不是新 WHO 选中成员的 WHAT。

额外加入“失败题均分”诊断对照：当前 Vote 错误时每个错误成员得 `1/m`，Vote 正确时为 0。它帮助区分每题规范化/目标归零与错误票结构归因的效果，不是新增运行算法。全零时记为未决，未擅自替新方法指定 fallback。

## 数学性质与附件核对

覆盖 16,807 种带标签配置，归并成 674 种错误类重命名后的配置；核对 26,570 条联盟边，并用全部修复排列独立复算 Shapley。效率性、非负性、同类对称性、Dummy、Immediate/Enabling 精确分解均通过。团队错误时每个错误成员都有正 Shapley；团队已正确时所有错误成员都是零。另将全部 16,807 种配置与当前生产聚合器逐项比较。

下表全是**人工合成类别**，A 为正确类，不含历史题目或答案。

| 配置 | 错误成员 Shapley | 最少修复人数 |
|---|---|---:|
| B B B B B | 每人 1/5 | 3 |
| A A B B B | 每个 B 为 1/3 | 1 |
| B B C D E | 每个 B 为 3/10；其余各 2/15 | 2 |
| A B B C D | 每个 B 为 5/12；其余各 1/12 | 1 |
| A A B C D | 全部错误成员为 0 | 0 |

附件数值全部正确。但“总责任规范化为一次失败的 1”不会自动偏好更接近翻转的**题目**：全错同类题总量和一步可修复的失败题总量都是 1，差别在成员间的分配。困难程度和真实可修复性仍需另证。

## WHO 与 Pattern 差异

以下相对固定父状态下重算的 Count，未把它误当历史实际 WHO。

| 诊断定义 | WHO 第一选择变化 /50 | Pattern 第一选择变化 /50 | 其中 Pattern 全零未决 |
|---|---:|---:|---:|
| Immediate | 21 | 29 | 6 |
| Oracle Shapley | 16 | 36 | 1 |
| 失败题均分对照 | 2 | 35 | 1 |

Shapley 的 16 次 WHO 改变均为正分最大集合与 Count 完全不相交。Pattern 的 36 次包含 35 次确定换首选及 1 次全零；其中 30 次为两个正分最大集合完全不相交，其余变化涉及并列。分数相同采用 Pattern ID 排序，不声称并列都代表严格偏好改变。

Shapley 与失败题均分对照之间，WHO 不同 14/50、Pattern 不同 10/50。因而 Pattern 对 Count 的大量差异不能全部归因于多阶段结构性贡献：排除团队已正确题、改变每题质量分配本身就能显著改排序。

逐机会重放中，2,181/8,359（26.1%）成员错误获得零 Shapley，全部来自 Vote 已正确的题。Count 在这些事件上的责任质量为 4,430.5。971 个全错行事件中，541 个有非均匀 Shapley；5,461 个成员错误事件是 Immediate 为零、Shapley 为正。后二者证明定义能识别多步机会，不能证明编辑器能够实现修复。

按 900 个不重复父状态—题目组合计，存在 253 个团队已正确的成员错误，Shapley 均归零；122 个全错组合均有正信号。五人全对的 613 个组合没有成员错误。原始各分层计数见 [diagnostic.json](diagnostic.json)。

## 与历史实际候选收益的关系

所有信号在该历史机会编辑前计算；结局取已有 Full 相对 incumbent 的实际净增，不以事后修复质量冒充预测信号。同一机会多个 Full 先平均，主要描述单位为 23 个机会。它们仍共享 6 个父状态，并非 23 个独立实验。

下表为 Spearman 相关系数，无显著性或泛化声明。

| 编辑前 WHO 原始分数 | 机会平均净 Vote | 机会平均目标正确净增 |
|---|---:|---:|
| Count | 0.018 | 0.705 |
| Immediate | 0.397 | 0.304 |
| Oracle Shapley | 0.290 | 0.510 |
| 失败题均分对照 | 0.150 | 0.347 |

| 编辑前 WHO 折扣分数 | 机会平均净 Vote | 机会平均目标正确净增 |
|---|---:|---:|
| Count | 0.138 | 0.508 |
| Immediate | 0.269 | 0.535 |
| Oracle Shapley | 0.211 | 0.468 |
| 失败题均分对照 | 0.211 | 0.433 |

| 原实际选中 Pattern 的编辑前分数 | 机会平均净 Vote | 机会平均目标正确净增 |
|---|---:|---:|
| Count | 0.191 | -0.184 |
| Immediate | 0.181 | -0.258 |
| Oracle Shapley | 0.180 | -0.183 |
| 失败题均分对照 | 0.124 | -0.278 |

再按相同父状态—目标成员合并成 15 组，WHO 原始分数与平均净 Vote 的相关为：Count -0.119、Immediate 0.547、Shapley 0.361、失败题均分 0.231。31 个候选逐行结果也保留于 JSON，明确不当成独立样本。

观察是：Shapley 的 WHO 原始分数比 Count 更贴近这些已见净 Vote，但并未优于 Immediate；保留失败折扣后差距更小。Pattern 分数没有显示胜过 Count 的关联。不能据此宣布任一方法具有更好预测性能，更不能声称换 WHO 会产生更好候选。

历史 31 个 Full 中只有 3 个净 Vote 正增、5 个持平、23 个负增。216 次目标修复中有 115 次发生在原来 Vote 已正确的题，另有 246 次目标正确性丢失。Shapley 对这些修复给零当前 Vote 边际价值是其目标定义的结果，不说明它们对冗余或未来演化无用。理想修复分数也不计真实编辑造成的正确题损害、invalid 改变与错误答案重新分组。

## 判断与后续边界

本次支持“Count 与修复博弈并不等价”和“Shapley 可精确表达全错场景中的多阶段结构贡献”。**尚不支持“现在替换 WHO/Pattern 就能改善优化”或“应直接进入 Feasibility-Aware 方法”。** 当前团队方法继续保持 V2.12。

历史样本由旧 WHO、原实际 Pattern、局部导出和 Probe/Full 晋级共同选择；同父未选成员没有等预算候选，未选 Pattern 没有对应编辑，缺失 Full 不能写成零。部分 Full 来自历史多步局部编辑链，也不能当作当前单步 Prompt Editor 分布的无偏抽样。关联计算使用旧流程已经存在的选择偏差样本；没有独立留出预测评估，未做候选分布概率估计，也没有重演反事实演化。

若后续要检验实际调度价值，需要另行预注册同父状态、多成员等预算的候选比较，固定编辑器、Pattern/Memory、评测与预算；将可实现性估计与被评估候选严格分开。任何真实调用都需要新的精确冻结与单次授权。本次未准备或授权该执行。论文新颖性和附件外部文献未在此次离线诊断中核验。
