An existing freeze cannot be overwritten.

The reusable verifier checks the complete physical inventory: schema, attempt ID, artifact count, unique safe relative paths, absence of symlinks, every size and SHA-256, and absence of missing or unlisted frozen artifacts. The known post-freeze trajectory file is permitted only when all frozen artifacts still verify.

Trajectory derivation runs that verifier first. It serializes every record with strict JSON, writes to a fresh temporary file, flushes and fsyncs, atomically publishes, then checks every JSONL record, record count, content, and SHA-256 on read-back. Neither freeze nor trajectory can publish a partial final file on an injected write failure. A post-processing failure leaves the completed search lifecycle unchanged; freeze/derive can be retried from the same completed run without another provider search.
