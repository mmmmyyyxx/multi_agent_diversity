# M2F Candidate-Specific Feedback Necessity Isolation

This report contains sanitized, analysis-ready evidence from the preregistered
seven-candidate paired causal control. F1 was a loss-blind second revision; F2
received the actual candidate-specific competence-loss evidence. Both arms used
one revision call per frozen source candidate and the same rollout evaluator.

The protocol gate passed: 14/14 cells completed, paired identities and budgets
matched, F1 loss-evidence leakage was zero, and no validation/test evaluation,
team commit, optimizer update, or parent mutation occurred.

The frozen descriptive classifier is `FEEDBACK_NECESSARY`. F2 retained all
source responsibility repairs (100% versus 61.5% for F1), had fewer aggregate
collateral losses (77 versus 83), produced three rather than two Common-Safe
compatibility rescues, and had higher VoteNet (16 versus 12). The mechanism
picture is mixed outside those primary directions: F2 CriticalNet was 26 versus
35 and OracleDelta was 10 versus 23. These competence-exchange quantities are
analysis metrics only and were never used for generation, ranking, or acceptance.

This directory excludes prompts, questions, gold/model answers, raw responses,
caches, credentials, endpoints, and absolute paths.
