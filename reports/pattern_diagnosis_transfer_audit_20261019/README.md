# Pattern 诊断准确性与修复泛化能力：历史证据报告

日期：2026-10-19。性质：只读、离线、事后证据分析；没有新模型调用、重评分或新实验。本报告不修改方法规范、历史评分、候选状态或运行授权。

## 结论

| 关键问题 | 当前判断 | 已有证据及边界 |
|---|---|---|
| 同一 Pattern 中的错题是否共享一种可迁移修复原则？ | **尚未验证** | 支持集与证据投影符合历史结构契约；尚无对各 Pattern 原则及全部支持题的独立语义适用性审查，不能给出诊断准确率。 |
| 根据 Pattern 修改 Prompt，能否修复未参与其诊断的同类错误？ | **尚未验证** | 存在未展示给 Optimizer 的支持题被修复，但它们参与过 Pattern 生成；诊断外 Validation 的错误类型尚未独立标注，不能算同类泛化。 |

这里的“尚未验证”既不是机制有效的证明，也不是无效的证明。最终正确率、结构校验通过、簇内题型相近或 Teacher 自己的解释，都不足以单独回答这两个问题。

每轮诊断输入等于父 Prompt 的全部当前 Optimize 错题；正式 Gradient 成功证据进入聚类/分区检查。按最大去重支持数选一个 Pattern，然后正式采样至多三道代表题。Optimizer 得到所选 Pattern、代表题及其对应 Gradient/诊断；非代表题原文与对应诊断不进入编辑输入。本次逐轮核对了这些集合关系，但没有将结构合规认定为语义正确。

## 2. 诊断覆盖与“准确性”不同

以下覆盖全部 60 机会，单位均为跨机会累计的题目观测，重复题可以多次出现。

| 环节 | 题次 | 含义 |
|---|---:|---|
| 输入诊断的当前错题 | 2158 | 全量错误输入覆盖 |
| 标记 ACTIONABLE 的 Gradient | 1957 | 运行机制认为可用于后续聚类，不是独立确认正确 |
| 诊断耗尽 | 197 | 没有可用证据，不补成成功诊断 |
| UNCERTAIN | 4 | 保留不确定状态 |
| 进入某个合法 Pattern 支持集 | 1267 | 所有 Pattern 的支持并集，不仅是选中的那个 |
| 可用 Gradient 但未分配 Pattern | 690 | 不能当作已形成可迁移原则 |

其中 `1957 + 197 + 4 = 2158`，`1267 + 690 = 1957`。ACTIONABLE 占全部输入 90.69%；被 Pattern 覆盖占全部输入 58.71%。**这两个比例都是覆盖指标，不是诊断准确率。** 未分配证据也不自动等于错误诊断。

诊断准确性需要核查：所描述的错误是否真实发生；同一原则是否适用于每道支持题；原则是否有边界而非“仔细检查”等泛泛建议；必要修复是否被误当成充分修复。当前没有覆盖各 Pattern 的这类独立标签，因此诊断语义准确率应标记“不可确定”，而不是零或结构通过率。

## 3. 修复观测：展示外不等于诊断外

记 E 为本轮父 Prompt 的全部 Optimize 错题，S 为所选 Pattern 的完整支持集，R 为实际展示代表题。`R ⊆ S ⊆ E`；`S\R` 未作为例题展示，但参与过该轮诊断，不能充当真正诊断外的测试集。

60 机会中 59 次有合法 Pattern，1 次退化为原始错题编辑；56 个候选完成测评，4 次生成耗尽。总决策为 **7 更新、49 拒绝、4 耗尽**。以下表格仅纳入 **55 个使用合法 Pattern 且完成测评的候选**，包含接受与拒绝候选；不将无测评结果的四次耗尽计成零修复。

| 范围 | 错误→正确 / 父错误观测 | 比例 |
|---|---:|---:|
| 展示代表题 R | 41 / 161 | 25.47% |
| 未展示的支持题 S\R | 31 / 125 | 24.80% |
| 全部所选支持题 S | 72 / 286 | 25.17% |
| 所选 Pattern 外的其他已诊断错误 E\S | 372 / 1689 | 22.02% |

分母是**题目与候选机会的组合次数**，不是独立题数、独立随机试验或独立请求数。同一父 Prompt 的 Solver 终端结果可能被缓存复用。39 个有未展示支持题且测评完成的机会中，21 个至少修复一道这样的题。三重复的未展示支持题修复分别为 7/30、9/42、15/53。

未展示支持题与其他错误的观测比例相差约 **2.78 个百分点**。这不是匹配对照：题目难度、错误类型、父 Prompt、实际编辑、采样与生成随机性未被控制；不报告显著性，不由此认定特定原则造成迁移。把一次策略改动称为实施了 Pattern 修复，还需检查候选实际是否落实其原则。

同一批 55 候选在 Optimize 上共修复 444 次、破坏原正确题 392 次；在 Validation 上修复 187 次、破坏原正确题 314 次。Validation 原错误观测共 1171 次，但缺少与目标原则独立对应的错误标签，**187/1171 不是同类泛化率**。这些是各候选相对自身父 Prompt 的累计变化，不是最终 Prompt 的净增益。

本节使用**原冻结评分中的正确/错误迁移**，不是已人工确认的数学推理修复率。仅统计通过 Validation 的七个更新会产生选择偏差；四次旧 Guard 耗尽也会影响可测候选集合。相关历史误拒见 [Guard 审计](../historical_candidate_guard_audit_20261015/README.md)，不得把旧 Guard 下存活候选的结果直接推广为新检查机制的结果。

## 4. 独立错误标注的离线准备与边界裁决

为准备后续机制验证，另对第一重复的初始父 Prompt 全部 40 道历史失分题逐题阅读原题、父作答和参考推导。审阅材料隐藏历史 Pattern、Gradient、候选内容与逐题候选结果；审阅者此前见过汇总统计，因此不是完全未知历史的双盲审查。单一 AI 审阅者的标签是可质疑的初步假设，不是人工金标准，也尚未完成与各 Pattern 的适用性对应核对。

用户于 2026-10-19 确认：以下六题从**数学推理修复主分析准备**中排除，保留历史评分、单独报告。

| 盲审编号 | 边界类别 | 判定范围 |
|---|---|---|
| Q002 | 百分比最终表示与评分边界 | 推导正确，不能直接当推理失败 |
| Q004 | 矩阵最终表示与评分边界 | 推导正确，不能直接当推理失败 |
| Q030 | 根式最终表示与评分边界 | 推导正确，不能直接当推理失败 |
| Q031 | 参考答案字段与参考推导不一致 | 不用该争议项验证推理修复，不重写历史 gold |
| Q038、Q039 | 最终区间符号损坏或解析失败 | 数学分析正确；损坏来源尚未定位 |

因此推理标注准备池余 **34 道**；六题不被静默删除，也不被补成已修复。这个裁决并不证明表示问题具体发生在模型、传输、序列化或评分器的哪个环节。对初始作答的判断也不能自动推广到该题在后续每个 Prompt 下的作答。本节纳入政策不回写第 3 节的原历史评分迁移计数；第 3 节仅作评分观测描述，不作为排除后数学推理主终点。

在当前初步窄标签中，仅三类各有三题：代入/展开保持每个带符号项、分式变换保留全部因子、最终解回代原约束。后者是必要检查，不保证充分修复；复合错误单列标记。按每类至少两道诊断题、一道留出题的建议规则，本池仅能提供三道同类留出题，无法支撑稳健有效性结论。完整脱敏分类和边界裁决摘要见 [标注摘要](annotation_summary.json)。这些标签尚未冻结，尚未物化诊断/留出划分。

## 5. 下一步怎样回答两个问题

以下是已讨论的验证方向，不是可运行协议、正式实验注册或 API 授权。

1. **先扩充并冻结独立错误标签。** 按具体失败原因及可执行修复原则标注，保留适用、不适用、不确定以及复合错误。避免为了凑样本而把“代数题”“粗心”等大类当成共享修复原则。
2. **在生成任何新 Pattern 之前留出。** 固定父 Prompt 与题池，将同类错误分成诊断 D 和留出 H；H 的原题、父错答、参考证据、Gradient 和标签都不能进入诊断、例题选择或编辑。全部适用抽样基础种子为 42，默认三重复。D 是本次诊断全集，这是相对旧“全量 Optimize 错题诊断”的显式新输入范围，需新身份与隔离验证。
3. **先审诊断，再看效果。** 检查生成的 Pattern 原则对其 D 支持题是否真实适用。报告适用数/全部支持数及不确定数，而非只留下语义纯簇。将原则映射到冻结标签时也遮蔽候选得分；无法对应或没有同类 H 时记不可评估，不换一个更好看的 Pattern。
4. **做同父、同例题、同候选预算的单步配对。** Raw 组与 Gradient–Pattern 组使用完全相同的代表题、父作答及参考证据，仅后者增加所选 Pattern 和代表题诊断。固定相同编辑块与生成/解析策略。这个比较隔离额外结构化诊断流程，不能单独区分 Gradient 与 Cluster；诊断成本额外披露，不声称总 Token 相等。
5. **先封存双方候选，再评估留出。** 不用 H 选择候选、触发重试、更新父池或停止。主要比较同类 H 的配对修复差，同时报告其他错误修复、原正确题退化、无候选/no-op/诊断失败与干预落实率。区分有效错误→正确、无效→正确和格式恢复，不只分析成功更新。

模型、数据继承、成员、缓存、预算、重试和访问范围仍须独立冻结并获得精确执行授权；现有历史记录或本报告不能代替。当前没有启动新实验。
