# Acceptance boundary

V1 exposes the changed valid final frontier, bounded by its frozen return policy.
V2 exposes every changed, valid, unique, locally Solver-evaluated proposal in the immutable opportunity. Local survival remains strict inside the same pinned GEPA core. Local delta and frontier membership are diagnostics only. TeamProbe, promotion, Full, Common-Safe, Shadow and atomic deployment use team measurements.

V2 uses public callbacks, a silent logger and no backend raw-state persistence to keep rejected text ephemeral. A complete-unit pre-iteration budget reserver bounds local calls; export itself performs no mutation or Solver evaluation.
