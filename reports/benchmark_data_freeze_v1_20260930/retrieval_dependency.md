# Retrieval dependency

`RETRIEVAL_ARTIFACT_STATUS = NOT_DOWNLOADED_UNFROZEN`.

HotpotQA and HoVer's GEPA systems use retrieval infrastructure. Benchmark
example files alone do not reproduce their complete systems. A later protocol
must identify corpus snapshot, preprocessing, document identifiers, index,
retrieval model/service, budgets and public task input. No large Wikipedia
corpus or index was downloaded or built here.

DATA_ALIGNMENT/SPLIT_ALIGNMENT are currently verified only for IFBench.
Its evaluator input fields are retained; evaluator integration is still HOLD.
The other four actual-data alignments are pending user download.
SYSTEM_ALIGNMENT is not FULL_GEPA_REPLICATION for any benchmark in this task.
