# Gate 3 Source-Record Subset

These files are byte-for-byte copies of selected artifacts generated by:

```text
runs_gate3_eight_update_v3_e6b2785_20260725_153657
```

They provide enough source evidence to independently audit the published Gate
3 funnel, scheduler, responsibility lifecycle, TCS context boundaries,
Solver recovery, rate limits, token usage, latency, and final aggregate
results.

## Included Records

| File | Purpose |
|---|---|
| `accuracy_results.csv` | Exact task-level aggregate result row |
| `accuracy_results.jsonl` | Exact structured aggregate result row and split identity |
| `experiment_runs.jsonl` | Run identity and source commit |
| `candidate_funnel.json` | Complete eight-update role and candidate funnel |
| `cost_summary.json` | Aggregate calls, tokens, latency, and candidate costs |
| `solver_recovery_summary.json` | Strict-parser recovery and terminal validity counts |
| `target_priority_audit.jsonl` | Per-update target pools, Pareto fronts, and selection |
| `responsibility_assignments.jsonl` | Seven versioned responsibility snapshots |
| `tcs_context_history.jsonl` | Context sizes, hashes, selected case IDs, and isolation schema |
| `llm_calls.jsonl` | Per-attempt role, status, retry, token, latency, and finish metadata |

`llm_calls.jsonl` contains call metadata only; it contains no request or
response payload.

## Explicit Exclusions

The subset excludes:

- the SQLite Solver cache;
- raw Solver responses and invalid response excerpts;
- Teacher, Critic, and Student response excerpts and repair-plan text;
- candidate and selected prompt bodies;
- questions, gold answers, and member answer payloads;
- full candidate-decision rows because they embed prompt bodies;
- checkpoint files and local filesystem paths.
