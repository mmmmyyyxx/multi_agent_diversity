# Open Scientific Questions

These are design questions, not activated policies or execution authorization.

| Question | Required decision before experiment |
|---|---|
| Local acceptance versus team transition | Define whether team-value candidates may survive strict local rejection, with a new engine identity and comparator |
| Pattern-aware causal hypothesis | Specify causal intervention, null comparator, evidence scope and no hidden target-policy changes |
| Long-term memory | Define memory content, update timing, trust boundary and history-independent control |
| LLM aggregation responsibility | Define counterfactual scoring and capability before enabling responsibility; current default fails closed |
| PUPA multi-member privacy | Define trusted/untrusted member boundaries, redaction and privacy/utility scoring before generalization |

Current Pattern and Memory are null. Benchmark data freeze, evaluator resources,
governed prep and independent authorization remain required before real execution.
