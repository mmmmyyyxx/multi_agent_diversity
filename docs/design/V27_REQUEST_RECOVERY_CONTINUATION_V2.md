# Bounded request recovery and explicit pre-cluster continuation

Current method: `unified_team_prompt_search_v2_7_request_recovery_v2`.
This amendment supersedes generated-membership failure classification in the
earlier bounded recovery contract. A generated duplicate or unknown support alias
is a typed rejected Cluster draw. The whole response is regenerated within the
existing three-draw budget. No alias is rewritten, removed or accepted by repair.
Three rejected draws produce the existing legal all-unassigned fallback. Internal
partition corruption, source, leakage, identity, ledger and unknown failures remain
fail-closed. All other output limits, generation, scientific gates and search
semantics remain frozen.

An explicitly authorized migration may import only an immutable, audited prefix
that aborted before the first opportunity at Cluster membership validation. It
requires a new method/source/attempt/cache/grant, a sealed parent inventory, exact
wire requests, independent member lanes, unchanged scorer/models/data and an exact
initial-state comparison. Imported Gradient and Cluster responses undergo current
validators and consume their original draw positions. Initial cache entries retain
parent realization provenance. No completed opportunity, selected candidate or
adaptive Memory is imported. This narrow mechanism is not generic checkpoint resume.
Original results, scores, cache and consumed authorization remain immutable.

The authorized seed86 continuation retains five Arm B members, Optimize150,
Shadow40, Solver16, Gradient8 and fifty opportunities. Its experiment-specific
`team_epoch_no_commit_v1` patience is four complete eligible-member epochs.
Cumulative charged Token has no ceiling (`null`), while exact per-request
reservations, bounded retries, finite call ceilings, usage reconciliation and
durable hash-chained accounting remain mandatory. These are explicit protocol
amendments, not universal cross-benchmark stopping or budget rules.

Parent and continuation Token/calls must be reported separately and together;
imports incur no new provider call and cannot hide historical retry costs.
Optimize/Shadow are adaptive evidence. Validation remains unauthorized and Test
sealed. Neither engineering recovery nor Commit count establishes efficacy.
