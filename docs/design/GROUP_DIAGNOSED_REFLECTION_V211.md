# V2.11 Group-Diagnosed Reflection and readable evidence projection

Method: `unified_team_prompt_search_v2_11_group_diagnosed_reflection_v1`.
This amendment changes auxiliary Reflection evidence and its presentation only.
V2.10 weighted WHO/Pattern responsibility, Individual Gradient generation and
clustering, support sampling, V2.9 three independent frozen Parent draws, pool
capacity/fitness, Memory retrieval/storage, complete Optimize evaluation,
Full/Shadow admission, joint final selection, Solver/scoring and stopping retain
their existing scientific semantics. Historical source/results remain immutable.

After all three Parent draws, freeze the selected Pattern's 1–3 Optimize supports
from the current deployed Root Team. Validate all five complete Prompts and native
profiles against example, member, Prompt, raw response/request and split provenance.
Validate target evidence against that snapshot. Include per-example correct,
wrong and invalid sets, actual answers/equivalence classes, plurality result and
the existing gold-replacement counterfactual. Correct-count arithmetic never
substitutes for Vote or margin computation. Root members are not historical pool
Parents. There are no added Solver requests or held-out reads.

One Group Diagnoser, independently accounted as `group_diagnosis`, uses the
unchanged optimizer model/provider and produces one shared result before the
three Reflection slots. It receives complete reference solutions, ordinary
responses and root Prompts; previews and audit hashes are not necessary in its
readable view. Canonical records retain every original trajectory and source.

Input schema `ROOT_TEAM_GROUP_DIAGNOSIS_INPUT_V1`; output
`ROOT_TEAM_GROUP_EXPERIENCE_V1`: exact status plus four independently nullable
entries (`wrong_peer_contrast`, `negative_experience`, `correct_peer_contrast`,
`positive_experience`). Each entry has observation, hypothesis and modification
implication, each 1–300 characters and combined at most 900, plus 1–3 unique
support records with actual example/member IDs. Contrast cites the target and
an appropriate other peer; positive/negative peer classes are checked per example.
All null requires `NO_SUPPORTED_INSIGHT`; nonempty requires `SUPPORTED_INSIGHT`.
Compact serialized output is at most 6,000 characters. Existing source-aware
abstraction and verbatim-copy guards reject example-specific contents. Exact
Pattern-only implications are rejected; these bounded checks do not prove truth,
novelty or causal validity of natural-language claims.

At most two accounted structural draws use unchanged evidence and last-error
metadata only. Exhaustion is explicitly `GENERATION_FAILED` with null experience,
not a successful no-insight diagnosis. Reflection continues with that labeled
failure. Provider, unknown, authorization, provenance and persistence errors fail
closed. Responses, rejects, canonical input and accepted output remain private.
The optimizer output ceiling is 4,096 plus existing 10-token measurement tolerance.
Group input has a 100,000 serialized UTF-8 byte ceiling and configured 131,072
context-token ceiling checked conservatively with existing byte-based reservation
plus 4,096 overhead and output reservation. These are frozen configuration limits,
not a claim about live provider availability. Over-limit evidence is infeasible;
no member deletion, response truncation or model fallback occurs.

Reflection schema `GROUP_DIAGNOSED_READABLE_REFLECTION_INPUT_V6`, instruction
`GROUP_DIAGNOSED_REFLECTION_INSTRUCTION_V1`, projection
`DIRECT_READABLE_REFLECTOR_VIEW_V3`. Preserve full selected Prompt, Pattern,
problems/gold, existing explicitly labeled 4,096-character reference view, Memory
and edit capacity. Preserve complete root/Parent response strings, correctness,
validity, truncation, invalid reason and solution status. Remove duplicated
`visible_solution` text and low-level provenance from the LLM projection only.
Root/Parent merge requires validated identical complete trajectories (including
request/source identity and response) and correctness, not matching Prompt hashes.
Merged observations explicitly apply to both; otherwise deliver both independently.
New LLM views use ordinary JSON with directly readable Unicode characters,
not ASCII Unicode escape sequences or offset references; JSON string syntax
still escapes quotes, control characters and mathematical backslashes correctly.
Root diagnosis keeps observed_failure, diagnosis and reusable_correction; keep
observed_failure conservatively because its distinct semantic value is not
mechanically identifiable. suggested_block/expected_effect remain canonical;
they are root diagnostic recommendations, not observations of a selected Parent.
Reflection chooses its block and already receives the full corrective direction.
This omission is a scientific input change with unknown efficacy, not a proof of
semantic redundancy. Memory cards and their original budgets are unchanged.

Group Experience is auxiliary Root Team evidence, not a new Pattern, hard negative
constraint, causal law or Parent-specific Responsibility. Reflection checks its
relevance to actual selected-parent responses, need not adopt any suggestion,
cannot copy peer Prompts or depend on inference-unavailable team information.
Existing guards additionally inspect peer response text. All Prompts still have
one editable block per candidate and a 3,000-character rendered limit.

Canonical/view records, wire sizes, preview removal, duplicate counts, group
status/support/class counts, raw outputs, draws and per-role Token usage persist
privately. Character counts, Token estimates and actual provider usage are distinct.
New binding/composition/cache/checkpoint/single-use scope prevent old execution
state or authorization reuse. New resource proofs add at most two group draws per
opportunity and no Solver calls. Draft preparation is not execution authorization.

Offline correctness does not establish improved Reflection quality, Vote, cost
efficiency or generalization. Future paid evaluation needs a new exact freeze and
authorization; bundled results cannot identify the separate contributions of
group diagnosis and evidence projection.
