# Gradient Pattern discovery V4 in V2.4

This shared clustering and responsibility contract is active through the complete
V2.4 policy bundle. The structured diagnostic and mutation contracts are defined
in [STRUCTURED_SYSTEM_PROMPT_V24.md](STRUCTURED_SYSTEM_PROMPT_V24.md).
Historical variants require original Git source; null Pattern is not current.

Responsibility selects WHO first. The unchanged D/N/C counts and raw
`max(4D, 2N, C)` value, failure discount, feasibility, ranking and equal plurality
remain shared physics. All selected-member incorrect Optimize examples, including
invalid and zero-responsibility rows, enter independent diagnosis; correct examples
remain available for preservation.

One fresh Gradient receives the complete ordinary response, the structured System
Prompt, target member, question, extracted prediction, correctness/invalidity,
reference answer and separately labeled bounded Optimize worked solution. It returns
ACTIONABLE or UNCERTAIN, observation, hypothesis, reusable correction, an advisory
block and expected effect. Written reasoning is optional; no hidden-reasoning
claim follows. Only actionable corrections enter gradients-only clustering.
The individual 400-character and generalized 600-character limits are unchanged.

`PATTERN_STRUCTURED_CONTENT_GUARD_V7` preserves bounded fixed-answer, entity,
example-fragment and calibrated numeric provenance detection while admitting
ordinary changes to answer presentation. All three blocks are editable. It does
not prove comprehensive semantic safety. Numeric detection retains shared V6
physics, described in [NUMERIC_PROVENANCE_GUARD_V5.md](NUMERIC_PROVENANCE_GUARD_V5.md).

Clustering receives only stable IDs and actionable corrections, encoded with
lossless opaque aliases. Questions, references, raw responses, scores, labels,
Memory and other member prompts are excluded. Shared behavior is grouped across
topics and paraphrases; distinct singletons are legal. There is no fixed cluster
count, minimum support, confidence rank or similarity threshold.

`GRADIENT_PATTERN_PARTITION_V2` requires a full disjoint partition of the actionable
universe into nonempty Pattern supports and unassigned IDs. The existing frozen
[completion policy](GRADIENT_PARTITION_COMPLETION_V1.md) may only append missing
known aliases to unassigned. Unknown, duplicate and overlapping memberships fail
closed. Canonical normalized descriptions merge deterministically. Explicit
supports determine Coverage and F; unassigned IDs do not contribute support.
Selection maximizes unchanged sample responsibility then canonical identity.

The order remains target selection, per-example diagnosis, clustering, Pattern
selection, bounded Memory retrieval and Layer1. No automatic Gradient or Pattern
Memory writes occur. V2.4 supplies disjoint Mutation/SearchValidation/TeamProbe,
six generations, four exports and 42 local evaluations. Each generation edits
one block. Local search never vetoes outer team admission. No meta-output cache
or semantic regeneration exists; transport retries retain frozen accounting.
