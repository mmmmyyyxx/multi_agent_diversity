## Uniform exceptional behavior

No errors: carry the Prompt, record NO_ERRORS_CARRY and continue to round20.
Malformed/non-executable candidate: allow at most two output draws using only
last structural failure metadata; the first legal draw stops. Exhaustion carries
the Prompt and records INVALID_CANDIDATE_CARRY. These are format checks, never
performance selection.
An otherwise legal unchanged block is accepted on its first draw and explicitly
recorded as UNCHANGED_LEGAL_CANDIDATE; it does not trigger extra generation.
Gradient exhaustion/UNCERTAIN and absent legal Patterns remain explicit;
C may generate its one candidate from its approved raw Batch
plus that diagnostic status. No Pattern or correction is fabricated.

Solver invalidity permits at most four semantic draws, first valid stops even if
wrong; preceding truncation alone enables the frozen 6144 recovery capacity,
otherwise3600. Provider/credential failures have **zero transport retries** and
abort the phase attempt, preserving completed cells and all evidence. Context,
source, authorization, ledger, resource and persistence failures also abort.
No automatic resume, efficacy stopping, fresh run or old scope reuse is allowed.
Partial execution is not a complete nine-cell result.
