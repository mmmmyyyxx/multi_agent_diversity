# Numeric provenance evidence calibration V6

`PATTERN_ABSTRACTION_SPECIFIC_CONTENT_GUARD_V6` changes the bounded deterministic
evidence threshold for declaring example-specific numeric leakage. It does not
change the definition of a Gradient. Bare numeric coincidence, including large
values, decimal precision and ordinary ratios, is insufficient evidence of
copying and produces telemetry warnings only.

Strong evidence remains a hard rejection: explicit numeric answer assertions,
copied instantiated expressions, matched value with matching unit, instance-bound
given/specified/provided/stated/observed/supplied cues, numeric overlap with a
source entity or quoted label, and numeric overlap with a long copied source
fragment. The stable reason codes and decisions are defined by
`search/numeric_provenance.py`. Numeric spans index normalized source fields;
private records retain values and source provenance. Public reports use hashes.
Magnitude or significant-digit count alone never supplies a strong reason.

This detector is a bounded heuristic, not proof of arbitrary semantic provenance.
Some generic constants can share source-bound contexts, and some paraphrased
leaks evade literal checks. No semantic oracle, population false-positive rate,
usefulness or scientific efficacy follows from passing the guard.
