# Current Implementation Specification

The sole active research architecture is Unified Team Prompt Search.
The [scientific principles](SCIENTIFIC_PRINCIPLES.md) constrain interpretation;
the [MATH scientific contract](MATH_SCIENTIFIC_CONTRACT.md) clarifies benchmark
measurement and admission. These clarifications add no algorithm or threshold.
The sole executable method is
`unified_team_prompt_search_v2_6_readable_evidence_v2`.
[The V2.5 scientific contract](RESPONSIBILITY_FALLBACK_REPAIR_V25.md) and
[flexible answer extraction amendment](FLEXIBLE_ANSWER_EXTRACTION_V3.md) and
[bounded output recovery amendment](GENERATED_OUTPUT_RECOVERY_V25.md) are normative.
The amendment supersedes the strict terminal-line parser rule.
The [role routing amendment](PROVIDER_ROLE_ROUTING_V1.md) binds current Solver
requests to OpenLux `gpt-4o-mini`; Reflection, Gradient and Pattern retain
`qwen3.7-flash` on `lwj`. It requires a fresh binding, cache and authorization
scope and changes no search or transition rule.
New execution uses scripts/run_experiment.py, MATHStructuredBinding,
CurrentPolicyBundle and build_current_team_prompt_search. Structured Role,
Strategy and Answer are editable; System is exactly rendered blocks and User
exactly raw problem. Explicit gold-blind final declarations and pinned mathematical
equivalence determine binary correctness. Four invalid semantic draws remain bounded.

Members with any Optimize error are eligible, including zero responsibility and
member-wrong/team-correct. Positive D/N/C responsibility retains priority and
failure discount; all-zero fallback is seeded and replayable. Gradient and Pattern
recover typed model-output failures within three draws, preserving valid partial evidence.
Source-aware symbolic provenance replaces literal-only overlap rejection. Integrity
and unknown exceptions remain fatal; rejected text never enters optimizer state.
Mutation3, SearchValidation3 and Independent TeamProbe6 are disjoint. Seen assigned
repair must actually improve binary correctness before Full, under frozen Probe
risk. Every safe evaluated local edit advances the temporary parent. Six generations,
42 local evaluations, four exports and two Full promotions remain fixed.

The [V3 transition contract](TRANSITION_TARGET_OR_TEAM_PROGRESS_V3.md) remains
normative: immutable initial competence floor, nonregressing Vote, target-or-team
progress, winner-only Shadow and atomic commit. Team epoch stopping is unchanged.
The floor is an aggregate initial Optimize correct count, not per-question
monotonicity. Current MATH invalidity remains observation-only apart from binary
incorrectness and vote eligibility; no extra zero-format-regression gate exists.
Oracle coverage and deployed Vote gains are separate observations. Local, Full,
Shadow, formal stopping and independent generalization have distinct evidence roles.
Private measured Memory includes mathematical and format failures; shared risk
contains closed generic categories only. No optimizer context enters Solver.

Older runtime identities cannot execute through current production. Historical
manifests and reports remain immutable evidence with their frozen source replay.
No old scoring, response cache, competence, Memory or consumed scope is reusable.
Current readiness and authorization live in manifests and the frontier.
The [formal execution extension](FORMAL_EXECUTION_AND_PAIRED_VALIDATION_V1.md)
adds a frozen finite formal resource scope, optional independent Gradient
parallelism, supplier-tariff reservations and separately authorized post-search
paired Validation. It changes no optimizer, admission, aggregation or scientific
stop rule; the fifty-opportunity/300-Validation choices are experiment settings.
The complete initial Role/Strategy/Answer artifact and execution seed are frozen
inputs, read by binding, interface policy, provider lanes, composition and scope.
The registered Arm B initial condition changes the Answer block only; initial
members remain identical and every block remains editable. Fresh canary subsets
are selected deterministically from development metadata with unseen-first priority
and a disclosed minimum prior-use supplement if the frozen pool is insufficient.
Their phase, seed, prior-use set, supplement counts and memberships enter run identity.
These initial-condition and membership choices change no optimization rule.
The parser amendment requires a fresh source/protocol/cache identity before paid
execution; no previously consumed or reviewed scope is reusable.
