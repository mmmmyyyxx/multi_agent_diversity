# V2.9 Vote-Guided Parent Population Search

This normative amendment supersedes the V2.8 Layer1 chain, disjoint local panels,
Probe promotion, preceding-attempt feedback and abstention. Its method identity
is `unified_team_prompt_search_v2_9_vote_parent_population_v1`. Historical source,
manifests, measurements and reports retain their original contracts.

Layer2 still determines WHO, Responsibility and one Gradient/Pattern direction.
Feasibility requires an actual member error; no initial accuracy quota applies.
Select up to three erroneous support examples of the selected Pattern using
seeded task-type round-robin. No correct-example preservation panel is introduced.
Reflection sees the reference and readable ordinary response, the labeled root
diagnosis and the actual cached response of the selected Parent. These distinct
observations never establish a parent-specific Responsibility or a causal rule.

Each member starts with its initial Prompt in an independent pool. Capacity is
three distinct canonical Prompt hashes. Fitness is the latest actual complete
Optimize Team Vote count divided by N, else complete Optimize member Accuracy/N.
Counts, ordered support hash, member lane, source, observation and scoring team's
ordered Prompt hashes/state are recorded. Mixed and stale team contexts are not
strictly comparable estimates of individual contribution. A three-example score
cannot enter the pool. Bootstrap uses the initial jointly measured Vote.

At opportunity start freeze the pool and draw three Parents with replacement.
For normalized fitness f, q_i = 0.1/K + 0.9 exp(4(f_i-max(f)))/sum_j exp(4(f_j-max(f))).
Every parent has positive probability, including zero fitness. The RNG is seeded
by the frozen scope, experiment seed, opportunity identity and member. Tie order
is ascending canonical Prompt SHA256. Draw all three before generation; no Child
from this opportunity can be a Parent in it.

Each slot makes one single-block Reflection edit. The three slots share the same
repair direction and examples. There is no inner SearchValidation loop, local
feedback, rank-based four-export limit or repair-count Probe gate. Output has
exactly target_block, new_content and change_summary. NO_SAFE_EDIT is invalid.
Each slot allows at most two typed output-contract draws on the same Parent and
evidence. No-op, duplicate, illegal structure/length, example copying and optimizer
dependencies fail generation. Unknown, provider/integrity and provenance errors
remain fatal. Exhaustion yields a failed slot, never a fabricated candidate.
No actionable Pattern yields no justified repair task and no Reflection call.

Every unique legal Child receives one complete Optimize member profile. That
profile yields member Accuracy proxy and actual Vote with the deployed fixed
Peers, without a second Solver realization. The actual Vote immediately replaces
the provisional proxy. Pool upsert evicts the lowest current fitness when capacity
is exceeded; no initial/deployed-parent quota exists. On tied scores keep the
ascending-hash top three. A pool member need not pass deployment guards.

During search existing single-member Full/Shadow admission and atomic commit
continue to govern the deployed team that Layer2 observes. Initial aggregate
competence floors, Vote nonregression and target-or-team progress are unchanged.
Candidate retention is independent of these deployment decisions. Search is
still terminated by frozen team-epoch no-Commit stopping or a resource ceiling.
Pool changes do not reset no-Commit epochs.

At closure select the maximum-fitness Prompt from each pool, with the same tie
order, and freeze exactly that proposed team. Jointly recompute complete Optimize
Vote from its actual member profiles, never sum historical fitness. Apply the
initial floor to each changed member, Vote nonregression against the last safe
incumbent. Final selection does not require an additional strict improvement over
the already optimized incumbent: a safely measured neutral assembly is valid.
This explicitly differs from per-opportunity deployment, whose strict progress
guard remains unchanged. It does not create an opportunity Commit or reset the
stopper. Apply the existing private Shadow Vote nonregression
and member-loss limit to every changed member in the single joint winner. This
generalizes single-member admission to simultaneous final assembly; it adds no
threshold or Preservation panel. No Shadow ranking, retries or reselection.
An unsafe combination is FINAL_ASSEMBLY_REJECTED. Keep the safe incumbent as a
separately labeled operational deployment, never report it as the chosen final
team. Incomplete joint evaluation is NOT_EVALUABLE. Validation needs final
admission and a separately frozen authorization; Test remains sealed.

Memory contains bounded per-member single-step measured experience: actual edit,
intent, edit-parent applicability, complete measurement context and admission.
Deliver whole readable cards, never numeric slicing instructions. Long edits
are explicitly omitted rather than truncated into incomplete rules. Experiences
are scoped observations, not universal failure/causal laws. No optimizer-only
context reaches Solver or aggregation.

Pool checkpoints bind exact method/source/attempt/seed/models/support/member
lanes and contain private reconstructable prompts, fitness and selection plans.
Validate the entire checksum and scope before changing live state. Persistence
or recovery never grants API authorization; interrupted slots are not silently
regenerated. Boundary recovery must restore team, profiles, Memory, history,
pool and stopping counters together under the same frozen identity.

Cost: at most 3N Optimize child evaluations and S Shadow evaluations per opportunity,
versus old 2N+78+S. Final Optimize recombination needs no new Solver requests;
final Shadow adds at most 5S. Bootstrap is at most 5(N+S). Four Solver semantic
draws, three Gradient/Cluster draws and transport multipliers remain bounded;
three Reflection slots have at most six output-contract draws. Actual token cost,
superiority, Team Vote gains and generalization are UNKNOWN without real study.
