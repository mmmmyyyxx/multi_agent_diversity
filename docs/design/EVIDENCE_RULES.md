# Evidence Rules

These rules constrain report classifiers and scientific claims.

1. **Audit is not intervention.** A zero-API counterfactual is retrospective
   evidence and cannot become causal support without a prospective intervention.
2. **No signal is not a negative result.** If the intervention is never reached
   (for example Student reach is zero), downstream efficacy was not evaluated.
3. **Throughput is not quality.** Report Student reach, candidate validity,
   feasibility, WOULD_COMMIT, validation transfer, Vote, and Oracle separately.
4. **Oracle is not Vote.** Increased member coverage cannot be labeled team
   performance improvement without the frozen team endpoint improving.
5. **Prospective evidence outranks reconstruction.** Missing historical fields
   remain unavailable; hashes cannot be inverted into unrecorded plan details.
6. Every future classifier declares exactly one evidence type:
   `retrospective`, `prospective`, `causal_fixed_parent`, or `online`.

These constraints govern interpretation, not candidate selection.
